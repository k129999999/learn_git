1、git基本配置
新建项目目录
$ mkdir learn_git

进入目录
$ cd learn_git/

初始化
$ git init

初始化后多了一个.git目录
$ ls -al
total 16
drwxr-xr-x 1 Admin 197121 0 Sep 18 17:11 ./
drwxr-xr-x 1 Admin 197121 0 Sep 18 17:10 ../
drwxr-xr-x 1 Admin 197121 0 Sep 18 17:11 .git/

配置用户名
$ git config --global user.name "xiejie"

配置邮箱
$ git config --global user.email "k129999999@sina.com"

检查配置
$ git config --global --list
filter.lfs.clean=git-lfs clean -- %f
filter.lfs.smudge=git-lfs smudge -- %f
filter.lfs.process=git-lfs filter-process
filter.lfs.required=true
user.name=xiejie
user.email=k129999999@sina.com


2、git操作流程
工作区—(git add)—缓存区—(git commit)—提交区

所有文件都在工作区编辑，然后通过git add . 添加到缓存区，使用git commit将缓存区的文件提交到提交区，通过git log可以查看每次提交的用户、时间以及备注


3、本地git同步到github
首先在github上注册，然后在github上新建仓库，之后就能看到两种访问方式
HTTPS：https://github.com/k129999999/learn_git.git
SSH：git@github.com:k129999999/learn_git.git

推荐ssh，首先生成公私钥
ssh-keygen -t rsa -C "k129999999@sina.com"
文件名重命名（不改，回车）
输入密码（不改，回车）
再次输入（不改，回车）
然后就在C:\Users\Admin\.ssh中生成了两个文件（.pub为公钥，不带后缀的是私钥）
打开公钥，复制内容，打开github里的settings-SSH and GPG keys-new ssh key-填入key，title可以不写
然后测试：ssh -T git@github.com
如果失败了，就添加一个config文件（这里原因是因为github.com并不会自动的转换为ssh.github.com，我们启动的是后者，而不是前者，这会导致time out的产生。）
Host github.com
User k129999999@sina.com
Hostname ssh.github.com
PreferredAuthentications publickey
IdentityFile ~/.ssh/id_rsa
Port 443
然后再次测试：ssh -T git@github.com

通了以后，就可以推送到GitHub了
git push -u origin main
如果
报错了：error: src refspec main does not match any
就执行git branch，查看一下git新建的分支（可能为master，改成main）
git branch -M main
然后再推送
（可以通过命令git config --global init.defaultBranch main修改全局设置为main）

origin相当于远程仓库的一个代号，可以换用其他名称

git remote add origin git@github.com:k129999999/learn_git.git
git branch -M main
git push -u origin main
